Swift Zip Manager

A native macOS archive manager.

Handles ZIP, TAR, GZ, 7Z, and RAR, including encrypted archives. Browse contents before extracting, drag files in from Finder, and pull out individual entries without unpacking everything.

Built entirely in SwiftUI. Currently in beta, heading toward 1.0.

Swift 5 · SwiftUI · CryptoKit · macOS 13.5+

RunProcess

A Spotlight-style command launcher.

A native macOS menu bar app that opens a floating command window on a global hotkey — with real-time output, Tab completion, persistent history, drag-and-drop file paths, and sudo handling.

Three appearance modes — None, Frosted Glass, and Liquid Glass — let it match the rest of your screen. Session mode keeps a persistent shell alive between launches.

The same idea is also rebuilt for the browser: a working macOS desktop with a mock shell that responds to 50+ commands. No install required.

SwiftUI · Process/Pipe · HTML · CSS · JavaScript · macOS 12.4+

TaskView

A macOS process management tool.

A native macOS utility for viewing and managing running processes. Reads process information directly from the system using libproc, sysctl, and Darwin APIs.

Process list with PID, name, CPU, and memory. Terminate with SIGTERM or force with SIGKILL. Search, filter, and auto-refresh.

Swift 5 · SwiftUI · libproc · sysctl · macOS 12.4+
