Swift Zip Manager

A native macOS archive manager.

Handles ZIP, TAR, GZ, 7Z, and RAR, including encrypted archives. Browse contents before extracting, drag files from Finder, and pull out individual files without unpacking everything.

Swift 5 · SwiftUI · CryptoKit · macOS 13.5+

RunProcess

A Spotlight-style command launcher.

A native macOS menu bar app that opens a floating command window on a global hotkey. Real-time output, Tab completion, persistent history, drag-and-drop paths, and sudo handling.

Also available as a browser demo — the same interface, rebuilt in HTML, CSS, and JavaScript.

SwiftUI · Process/Pipe · HTML · CSS · JavaScript
