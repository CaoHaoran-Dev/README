What I'm building.

Three tools, each made for the Mac.

Swift Zip Manager

A native macOS archive manager.

Handles ZIP, TAR, GZ, 7Z, and RAR, including encrypted archives. Browse contents before extracting, drag files from Finder, and pull out individual files without unpacking everything.

Swift 5 · SwiftUI · CryptoKit · macOS 13.5+

RunProcess

A Spotlight-style command launcher.

Lives in the menu bar and opens a floating command window on a global hotkey. Real-time output, Tab completion, persistent history, drag-and-drop file paths, and sudo handling.

SwiftUI · Process/Pipe · macOS 12.4+

Learn more › Download ›

RunProcess Web Demo

RunProcess, in your browser.

The same idea rebuilt in HTML, CSS, and JavaScript. A working macOS desktop — menu bar, draggable windows, Dock — with a mock shell that responds to 50+ commands.
