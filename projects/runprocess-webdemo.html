The desktop

A working macOS desktop recreated in the browser. Menu bar with functional dropdowns. Draggable and resizable windows with working close, minimize, and maximize buttons. A Dock that magnifies on hover. A wallpaper picker for changing the background.

The shell

A mock shell responds to 50+ commands with realistic output. It's not a real shell — no command actually executes — but it behaves like one for demonstration purposes. Tab completion and command history are backed by localStorage, so your session survives a page refresh.

Languages

Bilingual support, following the same pattern as the native app.

Why it exists

The native app requires macOS. The Web Demo runs anywhere. It's a way to try RunProcess without installing anything, and a way to show what the interface looks like without asking someone to open Xcode.
