TaskView

A native macOS utility for viewing and managing running processes. Built with SwiftUI, using libproc, sysctl, and Darwin APIs to read process information directly from the system.

Features

Process list with PID, name, CPU, and memory. Select a process to see details: user, start time, status, path, and parent PID. Terminate with SIGTERM, or force with SIGKILL.

Search and filter to find what you need. Auto-refresh keeps the list current.

Known issues

This is an alpha. Some user processes show a blank name, and some show Unix Time Zero as their start time. System processes like kernel_task and WindowServer cannot be terminated.
