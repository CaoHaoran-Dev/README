Formats

ZIP, TAR, GZ, 7Z, and RAR. Encrypted archives are supported. The app checks for the 7zz and RAR command-line tools on first launch and installs them in one click if they're missing.

Browsing

Open an archive without unpacking it. Contents show up in List or Grid view, whichever suits the archive better. Drag files in from Finder to add them. Extract or delete individual entries without touching the rest.

Interface

Built entirely in SwiftUI. Native window controls, native menus, native everything. Supports multiple languages. Auto-updates check through the GitHub API.

Developer Mode

A hidden mode for the workflows most people never need — the ones I do. Enable it if you know why you'd want it.
