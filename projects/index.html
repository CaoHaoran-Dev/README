Swift Zip Manager

A native macOS archive manager.

Handles ZIP, TAR, GZ, 7Z, and RAR, including encrypted archives. Browse contents before extracting, drag files in from Finder, and pull out individual entries without unpacking everything.

Built entirely in SwiftUI. Currently in beta, heading toward 1.0.

Swift 5 · SwiftUI · CryptoKit · macOS 13.5+

RunProcess

A Spotlight-style command launcher.

Lives in the menu bar and opens a floating command window on a global hotkey. Real-time output, Tab completion, persistent history, drag-and-drop file paths, and sudo handling.

Three appearance modes — None, Frosted Glass, and Liquid Glass — let it match the rest of your screen. Session mode keeps a persistent shell alive between launches.

SwiftUI · Process/Pipe · macOS 12.4+

RunProcess Web Demo

RunProcess, in your browser.

The same idea rebuilt in HTML, CSS, and JavaScript. A working macOS desktop — menu bar, draggable windows, Dock — with a mock shell that responds to 50+ commands.

No download, no install, entirely frontend.
