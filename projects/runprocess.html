RunProcess

A Spotlight-style command launcher for macOS.

‹ All projects

A lightweight menu bar app that wraps /bin/zsh in a polished, translucent floating window. Real-time output, Tab completion, command history, drag-and-drop file paths, sudo support with in-memory password handling, and a global hotkey.

Three appearance modes — None, Frosted Glass, and Liquid Glass (macOS 26+) — with session mode for persistent shell state.

Highlights

Real-time stdout/stderr via Process and Pipe. Tab completion backed by shell introspection. Command history persisted across launches. Drag files from Finder to insert their paths. Sudo prompts handled without writing the password to disk.
