RunProcess

A Spotlight-style command launcher — native and in the browser.

‹ All projects

RunProcess began as a native macOS app: a menu bar utility that wraps /bin/zsh in a polished, translucent floating window. The same idea was then rebuilt for the browser, so anyone can try it without installing anything.

Native macOS app

A menu bar app that opens a floating command window on a global hotkey, disappears when you're done. Built for the commands you run every day.

Running commands

Output streams in real time through Process and Pipe. Tab completion works the way you expect. Command history persists across launches, so yesterday's long ffmpeg invocation is one keystroke away.

Working with files

Drag files in from Finder to insert their full paths. Handy for anything that takes a path as an argument.

Sudo

When a command needs elevated privileges, RunProcess prompts for the password and holds it in memory for the session. It's never written to disk.

Appearance

Three modes — None, Frosted Glass, and Liquid Glass (macOS 26+) — let the window match whatever the rest of your screen is doing. None is a flat panel. Frosted Glass blurs what's behind it. Liquid Glass is the newer macOS material.

Session mode

By default, each window is its own shell. Session mode keeps a persistent shell alive between launches — environment variables, working directory, and history all carry over.

Web Demo

The same idea rebuilt in HTML, CSS, and JavaScript. No download, no install — open it and use it. Entirely frontend, no backend.

The desktop

A working macOS desktop recreated in the browser. Menu bar with functional dropdowns. Draggable and resizable windows with working close, minimize, and maximize buttons. A Dock that magnifies on hover. A wallpaper picker for changing the background.

The shell

A mock shell responds to 50+ commands with realistic output. It's not a real shell — no command actually executes — but it behaves like one for demonstration purposes. Tab completion and command history are backed by localStorage, so your session survives a page refresh.

Why it exists

The native app requires macOS. The Web Demo runs anywhere. It's a way to try RunProcess without installing anything, and a way to show what the interface looks like without asking someone to open Xcode.
