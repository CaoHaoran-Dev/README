Swift Zip Manager

原生 macOS 压缩包管理器。

支持 ZIP、TAR、GZ、7Z 和 RAR，包括加密压缩包。解压前可先浏览内容，从 Finder 拖入文件，也能单独取出某个条目而不必整体解压。

完全用 SwiftUI 构建。目前处于 beta，正朝 1.0 前进。

Swift 5 · SwiftUI · CryptoKit · macOS 13.5+

RunProcess

Spotlight 风格命令启动器。

常驻菜单栏的 macOS 应用，通过全局快捷键打开浮动命令窗口——实时输出、Tab 补全、持久化历史、拖拽文件路径，以及 sudo 处理。

三种外观模式——None、Frosted Glass 和 Liquid Glass——让它与屏幕其余部分保持一致。会话模式会在多次启动之间保持一个常驻 shell。

同样的想法也重做成了浏览器版：一个可用的 macOS 桌面，配一个能响应 50+ 命令的模拟 shell。无需安装。

SwiftUI · Process/Pipe · HTML · CSS · JavaScript · macOS 12.4+

TaskView

macOS 进程管理工具。

一个查看和管理运行中进程的原生 macOS 工具。通过 libproc、sysctl 和 Darwin API 直接从系统读取进程信息。

进程列表含 PID、名称、CPU 和内存。可用 SIGTERM 终止或用 SIGKILL 强制结束。支持搜索、过滤和自动刷新。

Swift 5 · SwiftUI · libproc · sysctl · macOS 12.4+
