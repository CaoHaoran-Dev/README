TaskView

macOS 进程管理工具。

‹ 所有项目

一个查看和管理运行中进程的原生 macOS 工具。用 SwiftUI 构建，通过 libproc、sysctl 和 Darwin API 直接从系统读取进程信息。

下载 macOS 版 需要 macOS 12.4 或更高版本
版本1.0.0-Alpha.1
状态开发中
平台macOS 12.4+
语言Swift 5
框架SwiftUI · libproc · sysctl
许可证GPL-3.0

功能

进程列表含 PID、名称、CPU 和内存。选中某个进程可查看详情：用户、启动时间、状态、路径和父进程 PID。可用 SIGTERM 终止，或用 SIGKILL 强制结束。

支持搜索和过滤，快速找到想要的进程。自动刷新保持列表最新。

已知问题

这还是 alpha 版。部分用户进程名称显示为空，部分启动时间显示为 Unix 零点。像 kernel_task、WindowServer 这样的系统进程无法终止。
