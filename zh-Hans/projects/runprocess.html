原生 macOS 应用

一个菜单栏应用，通过全局快捷键打开浮动命令窗口，用完即走。为那些你每天都在跑的命令而做。

运行命令

输出通过 Process 和 Pipe 实时流式返回。Tab 补全按你预期的方式工作。命令历史在多次启动之间保留，昨天那条很长的 ffmpeg 调用只差一次按键。

处理文件

从 Finder 拖入文件即可插入完整路径。对任何以路径为参数的命令都很方便。

Sudo

当命令需要提权时，RunProcess 会提示输入密码，并在会话期间保存在内存中。绝不写入磁盘。

外观

三种模式——None、Frosted Glass 和 Liquid Glass（macOS 26+）——让窗口与屏幕其余部分保持一致。None 是平面面板。Frosted Glass 会模糊背后的内容。Liquid Glass 是更新的 macOS 材质。

会话模式

默认情况下，每个窗口是自己的 shell。会话模式会在多次启动之间保持一个常驻 shell——环境变量、工作目录和历史都会保留。

Web Demo

同样的想法用 HTML、CSS 和 JavaScript 重建。无需下载、无需安装——打开即用。完全前端，没有后端。

桌面

在浏览器里重建的一个可用 macOS 桌面。带可用下拉菜单的菜单栏。可拖动、可调整大小，关闭、最小化、最大化按钮都能用。悬停会放大的 Dock。可更换背景的壁纸选择器。

Shell

一个模拟 shell 能对 50+ 命令返回逼真的输出。它不是真正的 shell——没有任何命令真的执行——但用于演示时，它的行为和真的一样。Tab 补全和命令历史由 localStorage 支撑，所以刷新页面后会话依然保留。

为什么做它

原生应用需要 macOS。Web Demo 可以在任何地方运行。它是一种无需安装就能试用 RunProcess 的方式，也是一种不必让人打开 Xcode 就能展示界面长相的方式。
