Swift Zip Manager

原生 macOS 压缩包管理器。

‹ 所有项目

一个感觉本就属于 Mac 的压缩包工具。用 Swift 和 SwiftUI 构建，设计上尽量不打扰你。

格式

ZIP、TAR、GZ、7Z 和 RAR。支持加密压缩包。首次启动时会检查 7zz 和 RAR 命令行工具，缺失时可一键安装。

浏览

无需解压即可打开压缩包。内容以列表或网格视图显示，哪种更适合就用哪种。可从 Finder 拖入文件。可单独解压或删除某个条目，不影响其余内容。

界面

完全用 SwiftUI 构建。原生窗口控件、原生菜单、原生的一切。支持多语言。通过 GitHub API 检查自动更新。

开发者模式

一个隐藏模式，面向大多数人从不需要、但我需要的工作流。如果你清楚自己为什么需要它，再打开。
